📦 Sing-box JSON

原生 JSON 格式，支持所有协议（含 Hysteria2 / TUIC / VLESS）。Android/iOS 首选。

⚔️ Clash Meta / Mihomo YAML

Android iOS Windows macOS Linux

Clash Meta (Mihomo) 内核配置，支持所有协议包括 Hysteria2 / TUIC。功能最完整的 Clash 变体。

✅ 完整协议支持 + DNS 防污染 + AI 解锁规则 + 流媒体分流

🌀 Clash 基础版 YAML

Android iOS Windows macOS

Clash 原版配置，过滤了 Hysteria2 / TUIC 等不支持的协议，仅输出 ss/vmess/vless/trojan。

⚠️ 仅支持 ss / vmess / vless / trojan 协议（Clash 原版不含 hysteria2/tuic）

🐱 NekoBox 混合

Android iOS

NekoBox 支持导入 Clash YAML 和 Sing-box JSON 两种格式。推荐 Sing-box 格式以获得完整协议支持。

✅ 推荐 Sing-box 格式（完整协议）；Clash 格式兼容但不含 hysteria2/tuic

🔮 Karing 混合

Android iOS

Karing 支持 Clash Meta 和 Sing-box 格式，功能强大，支持规则引擎和策略组。

✅ 推荐 Sing-box 格式；Clash Meta 格式含完整规则和分流

🎯 V2rayN YAML

Windows Linux

V2rayN 使用 Clash Meta (Mihomo) 格式，支持所有协议。导入订阅后自动更新。

✅ 使用 Clash Meta 格式，支持 hysteria2 / tuic / vless / trojan 等全协议

📲 Stash (iOS) YAML

iOS macOS

Stash 是 iOS 上功能最强大的 Clash 客户端，支持 Clash Meta 格式。

✅ 使用 Clash Meta 格式，支持所有协议和高级规则
